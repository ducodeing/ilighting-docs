附录 · 网络排错命令速查卡

Windows / Linux 双平台，调试现场随身查
Windows 侧 8 条必背
ipconfig /all 看本机 IP/网关/DNS
ping 192.168.1.1 先 ping 网关
ping -t 192.168.1.100 持续 ping 看丢包（Ctrl+C 停）
tracert -d 192.168.1.100 追踪路由，看卡在哪一跳
telnet 192.168.1.100 80 测端口（黑屏=通）
Test-NetConnection 192.168.1.100 -Port 80 Win10/11 替代 telnet
arp -a 看同网段设备
netstat -ano | findstr ":1883" 查端口占用（MQTT）
Linux 侧必会命令
ip addr show 看本机 IP/网卡
ping 192.168.1.1 先 ping 网关
ping -c 4 192.168.1.100 只发 4 个包看丢包
traceroute 192.168.1.100 追踪路由
nc -zv 192.168.1.100 80 测端口
ss -tulnp | grep :1883 查端口占用与进程
ip neigh 看同网段邻居
systemctl status 服务名 看服务状态 / restart 重启
df -h · free -h 磁盘 / 内存
journalctl -u 服务名 -f 实时滚动服务日志
排查顺序（照做）：先看自己 IP → ping 网关 → ping 服务器 → 追路由 → 测端口。注意「ping 不通 ≠ 设备离线」，很多设备禁了 ICMP，要用 Test-NetConnection / nc 测具体端口。

第一篇　智控方案工序速查

智控方案的点位图、系统图、桥架路由图，工序是固定的七步。每一步真正在反复用的命令不超过三个，其余都是辅助。卡在哪一步，就查对应那一节。

图 1　智控方案 CAD 七步工作流

0　常用命令操作流程顶部那张表里的每条命令，这里给完整走法

快捷键只是入口，真正卡住人的是"输完之后该点什么"。这一节把面板里的 31 条命令逐条拆成步骤，按左列顺序排列：图层与块 → 画图与对齐 → 修整 → 标注 → 统计 → 出图。每条最后的黄框是这一步最容易做错的地方。

先记住三个通用动作，所有命令都通用：① 输入命令后按空格执行（空格＝回车）；② 选完对象按回车确认选择集；③ 任何时候按 Esc 退出当前命令。下面每条流程里，"回车"出现的位置就是这三个动作。
LA新建图层
  1. 输 LA 回车，打开图层管理器
  2. 点左上「新建图层」（或 Alt+N）
  3. 直接输名字，回车确认
  4. 点颜色列选色号（点位用 3 绿、桥架用 4 青）
  5. 关闭对话框，图层已可用
命名习惯：点位-灯具、路由-桥架，前面带序号更好排序
LA复制图层
  1. 选中要复制的那一层（不要点开灯泡）
  2. 右键 →「复制图层」（2019 及以上版本）
  3. 改名、改颜色，其余特性全部继承
老版本无此菜单：新建一层后用 MA 把源层对象的特性刷过来
LA设为当前层 / 开关锁定
  1. 双击层名 = 设为当前层（前面出现绿勾）
  2. 点「灯泡」列：关 = 看不见也打印不出
  3. 点「锁」列：锁定 = 看得见、能捕捉，但选不中
底图一定「锁定 + 置灰 + 置后」，避免误删误改
B创建块
  1. 先把图例画好（一个灯具符号就是一个块）
  2. 输 B 回车，输块名（带型号，如 GS-筒灯）
  3. 点「拾取点」，选图例的中心或插入基准角
  4. 点「选择对象」，框选全部图元，回车
  5. 确定。基点选错，后面所有插入都会偏
基点决定定位精度：能抓圆心就抓圆心，不要随手点
CO复制块 / 复制点位
  1. 输 CO 回车，选块，回车
  2. 点一个基点（块中心最好）
  3. 点目标位置，可连续点多个
  4. Esc 结束。要精确就开 F3 抓墙边、轴网交点
跨图纸搬点位用 Ctrl+Shift+C 带基点复制，落点一次到位
I插入块
  1. 输 I 回车，列表里选块名
  2. 勾「在屏幕上指定」，确定
  3. 图上点位置；提示缩放与角度时直接回车取默认
  4. 同一块重复插：再按一次 I 或空格重复上一命令
列表里杂块太多，先 PU 清理一次
BE改图例（全图同步）
  1. 双击任意一个该图例的块
  2. 进入块编辑器，改线型、加文字都行
  3. 点「关闭块编辑器」→「保存修改」
  4. 全图同名块一次性更新，包括已复制出去的
不要用 X 炸开再改——炸开后就不再是块，也没法统计
ATT加块属性（回路号/地址号）
  1. 在图例旁输 ATT 回车
  2. 填「标记」（如 LOOP）、「提示」、「默认值」
  3. 指定文字高度与位置，放在图例下方
  4. 再连同属性一起 B 建成块
  5. 插入时逐块填值；已插入的用 AD 或双击改
属性是设备清单的字段来源，标签规则（如 GS1A7）要在建块时就定死
W存成独立图例文件
  1. 输 W 回车，选「对象」
  2. 框选图例，回车
  3. 指定基点（同建块）
  4. 给文件名，保存为独立 DWG，进公司图例库
以后任何图纸 I 插入即可，不用重画
L画线
  1. 输 L 回车，点起点
  2. 按 F8 开正交，或 F10 极轴锁角度
  3. 长度已知就输 @3000,0（右 3000）或 @3000<90（向上 3000）
  4. 回车 / Esc 结束
所有精确作图都靠 @ 相对坐标，比拉鼠标靠谱
O平行复制（偏移）
  1. 输 O 回车，输距离（如 300）
  2. 点原对象，再点要偏的那一侧
  3. 继续点可连续偏移多条
  4. Esc 结束。均分时距离栏直接输 3000/4
墙体、桥架双线、灯带并行线全靠它；偏移后原来的线还在，别忘了删
AL图形对齐
  1. 输 AL 回车，选要挪的图形，回车
  2. 点第 1 个源点（图形上的特征点）
  3. 点第 1 个目标点（要对到哪）
  4. 同上给第 2 组点（决定旋转方向）
  5. 问「是否基于对齐点缩放」：只要挪动+旋转输 N，要连比例一起对输 Y
找对齐点用 F3 抓端点，别靠眼估
AL块对齐
  1. 同样输 AL，选块时整体作为一个对象
  2. 源点抓块的插入点或角点，目标点抓墙线端点
  3. 两组点给完回车；只想平移不必旋转时用 M 更快
块内若含属性文字，对齐后注意文字角度是否被带歪
M移动
  1. 输 M 回车，选对象，回车
  2. 点基点（抓端点或圆心）
  3. 点目标点；要精确距离输 @0,500 这类相对值
移动前确认没锁层，锁层里的对象选不中
RO旋转（可连复制）
  1. 输 RO 回车，选对象，回车
  2. 点基点（旋转中心）
  3. 输角度（逆时针为正，如 90）
  4. 需要保留原件：命令里先输 C 再给角度
  5. 要按已有角度对齐：输 R，点参照两点再输新角度
斜房间排灯：RO → C → 打角度，一步出整排
SC缩放
  1. 输 SC 回车，选对象，回车
  2. 点基点，输比例（放大 2 倍输 2，缩小一半输 0.5）
  3. 按目标尺寸缩：输 R → 点两点给现有长度 → 输目标长度
  4. 也可直接输算式：50/80.25
整图比例不对时用它把底图缩到真实轴距
MI镜像
  1. 输 MI 回车，选对象，回车
  2. 点镜像线上的两点（对称轴）
  3. 提示「是否删除源对象」：对称房间选 N 保留
文字反写：先设 MIRRTEXT=0 再镜像
AR阵列排灯
  1. 输 AR 回车，选对象，回车
  2. 选「矩形」
  3. 给列数、行数与间距（或点「间距」输具体值）
  4. 关闭阵列面板；不满意可双击阵列改参数
规则吊顶排灯一次成排；不规则布置还是 CO 复制更快
DIV沿线等分布点
  1. 输 DIV 回车，选线
  2. 输份数（如 8），线上自动生成 7 个节点
  3. 捕捉时用 NOD（节点）抓这些点放图例
点看不见：格式 → 点样式，把点大小调到 5% 以上
TR修剪
  1. 输 TR 回车
  2. 直接回车（不选边界，全部对象当边界）
  3. 点要剪掉的那一段，或框选一片
  4. 要一笔剪一串：输 F 栏选，画一条线穿过所有要剪的段
老习惯「先选边界」容易出错，新版空回车最快
EX延伸
  1. 输 EX 回车，再回车（全部为边界）
  2. 点要延伸的那一端（点哪头往哪头长）
  3. 延伸不到位时，说明边界太远，可选具体边界对象
EX 里按 Shift 立刻变修剪，反之亦然，不用切命令
S拉伸（改尺寸）
  1. 输 S 回车
  2. 用窗交选择：从右下往左上框，框住要动的端点
  3. 回车，点基点，点目标点（或输位移 @1000,0）
框住整条线是移动，框住一端才是拉伸——这是最容易做错的一步
F圆角 / 剪角
  1. 输 F 回车
  2. 输 R 设半径：要圆角给实际值，要剪角就输 0
  3. 依次点两条线，自动连成直角或圆角
半径 0 的 F 比 TR 还好用，两根不相接的线一步接齐
X分解
  1. 输 X 回车，选块，回车
  2. 嵌套块要连续执行几次，直到命令行不再提示
  3. 注意：炸开后不再参与块统计，能不炸就不炸
底图炸不开时先 XC 剪裁本层，再炸
DataExtraction数数量出设备清单
  1. 输 DATAEXTRACTION 回车（无简写）
  2. 选「新建数据提取」，命名保存
  3. 数据源选「当前图形」，勾选「块」
  4. 勾要统计的块名（灯具、面板、传感器）
  5. 输出选「表格」，插入图纸或导出 Excel
点位不是块就统计不出来——这是统计失败的第一原因
QSELECT按块名查数量
  1. 输 QSELECT 回车
  2. 对象类型选「块参照」，特性选「名称」
  3. 运算符「=」，值下拉选块名，确定
  4. 状态栏/特性面板立刻显示选中数量
报量前逐个块名核一遍，比肉眼数图可靠
DLI标尺寸（线性）
  1. 输 DLI 回车
  2. 点第一条尺寸界线原点（墙边、轴线）
  3. 点第二条原点
  4. 点尺寸线摆放位置，完成
先标第一条，后面的连续标注才有起点
DCO连续标注
  1. 先有一条 DLI 标注
  2. 输 DCO 回车，自动接上一条
  3. 依次点后续各点，尺寸自动串起来
  4. 回车结束；一排房间开间一次标完
标出来的字太小/太大：D 改标注样式里的文字高度与全局比例
LE引线＋回路号
  1. 输 LE 回车
  2. 点箭头落点（指向设备）
  3. 点文字位置
  4. 输文字（如 L1-03 至面板P2），回车两次结束
引线箭头与字高也在标注样式里统一，别每根单独调
DT写字（单行/多行）
  1. 单行输 DT：点起点 → 输字高 → 输角度（0）→ 打字 → 回车两次
  2. 多行输 MT：框一个矩形 → 弹窗里打字 → 关闭
  3. 字高按出图比例定：1:100 用 250~300
字号样式先建好（ST），别每次现调
Ctrl+P打印出图
  1. Ctrl+P 打开打印对话框
  2. 打印机选 DWG To PDF 或实际打印机
  3. 图纸尺寸、打印区域（窗口 / 范围）
  4. 勾「居中打印」，打印样式表选公司 CTB
  5. 预览确认 → 确定出图
线宽靠 CTB 按颜色控制；预览里线粗了细了改 CTB，不要改图层线宽
Z+E显示全图
  1. 输 Z 回车，再输 E 回车
  2. 或直接双击鼠标滚轮，更快
  3. 看局部：滚轮缩放，按住滚轮拖动平移
图「丢了」先双击滚轮；还看不见就是图层被关了
Ctrl+9找回命令行
  1. 按 Ctrl+9，命令行开关切换
  2. 界面乱了按 Ctrl+0 清理屏幕
  3. 命令输错按 Esc 退出，不要连按回车
命令行被关掉时，一切快捷键都失效，这是新手最常见的事故

2.1　特例：天幕点位图怎么画

天幕（SDL）跟常规点位图不是一套画法：它不是"布灯"，是按网格排灯板，一个灯盘内 6×6 块灯板、间距 100 mm，整片就是一个规整矩阵。画错一格，现场就错一位，所以顺序和图层要卡死。

  1. 四个图层分开：SDL-轮廓（灯盘外框）、SDL-灯片（灯板块）、SDL-路径（串的走向与箭头）、SDL-文字（串号、控制器号）。不要和常规灯具层混用。
  2. 房间按实际尺寸画，灯盘 600×600 用 AR 矩形阵列：先算列数与排数（如 6 列 × 4 排），列距＝灯盘宽、行距＝灯盘高，一次成图。
  3. 灯板做成 75×75 的块（按实际模组尺寸），在灯盘内 AR 6 列 × 6 行、间距 100 mm；再用 B 存成独立图例，全项目复用。
  4. 路径用 PL 画蛇形折线，只画一条串的走向，加箭头表示首尾；每串起点就是控制器出线的第一块灯板，起点的位置必须与现场一致。
  5. 统计靠数据提取：QSELECT 按块名数灯板，或用数据提取出"灯板数／灯盘数／串数"三列；不要用眼睛数，一块错就是 36 点错。
  6. 出图比例 1:50（局部大样 1:20），字高 3.5，路径线用虚线以区别于强电。
两个易错点：① 被吊顶遮挡的灯盘也要画——它仍在串上，漏画会让后面所有点的序号错位；② 路径之间不要连成一条，每条串独立起落（CAD 里就是多个独立多段线），现场在平台上也是逐条右键收尾。

8　十个反复踩的坑每条一句话，看一遍省半天

  1. 底图炸不开：嵌套块要连炸几次；实在炸不动先 XC 剪裁再试。
  2. 捕捉不到点：先看 F3 是否关闭，再看 OS 里端点/中点是否勾选。
  3. 画的点位看不见：被墙线压住，DRAWORDER 把底图后置。
  4. 虚线变实线：LTS 线型比例不对，不是线型没加载。
  5. 镜像后文字反了：设 MIRRTEXT=0，改完重镜像一次。
  1. 偏移点不准：捕捉被正交/极轴带偏，临时 Shift+右键指定捕捉。
  2. 阵列后数量翻倍：原对象没删，阵列前先确认选择集。
  3. 文件越来越大：底图直接粘进来而非参照，且从未 PU。
  4. 打印少线：图层被设为"不打印"，或线宽为 0 又被 CTB 忽略。
  5. 交付对方缺参照：没有 ETRANSMIT 打包，外部参照路径是绝对路径。

22　图层与线型：图面的语法

单位与比例先定死。DWG 一律按毫米公制建模（INSUNITS=4、MEASUREMENT=1），模型空间按 1:1 实际尺寸绘制；比例只出现在图签的比例栏里，不在图名里自行放大缩小。平面图常用 1:100，大空间 1:150～1:200，详图 1:20～1:50。图幅按 GB/T 50001 选 A0～A4，同一套图尽量统一幅面。

图层按“前缀-用途”命名，一层绑一套颜色、线型、线宽。这是让图能被别人读懂的底线，也是审查时最先被看的地方。

24　定位与标注：三行字说清一盏灯

灯具标注按 GB/T 50786 的格式，一行字要包含五件事：

a-b c×d e-f 4-OPPLE-TJ-18W 1×18 3.0-吸顶

读法：a 同型数量、b 型号或图例编号、c×d 光源数量 × 单光源功率、e 安装高度（m）、f 安装方式。嵌入式灯具（筒灯、面板灯）不标高度、只标“嵌入”；吸顶、壁装、吊装必须标高度。

同一排同型灯具只在第一只写全标注，其余用编号（如 L1-12）代替，编号与图例表对应。功率若含驱动损耗，要在说明里注明口径，保证与 LPD 核算一致。

25　走线与路由：四条铁律

  1. 横平竖直。所有导线段只画水平或垂直方向，转弯为 90° 折线，禁止斜拉乱穿。
  2. 成束走主干。同一回路先沿墙边或轴线走一条主干通道，再垂直引出支线接灯；不要每只灯都从配电箱单独拉一条线。
  3. 连接才加点。十字相交且电气相连处画实心圆点；只交叉不相连的地方不许加点，并尽量错位绕行减少交叉。
  4. 线不重叠。平行相邻导线保持可分辨间距，一根线不得穿过另一根线的连接点。

质量红线：不允许出现“从开关直接斜穿房间连到对角灯”的走线；所有连线端点必须捕捉到图块插入点，不能目测搭上。

26　交付与审查：能不能交，会不会被挑刺

照明施工图交付六件套：图纸目录、设计施工说明、图例表、照明平面布置图、灯具配电平面图、照明配电系统图，另加应急照明平面图与安装大样。少一件都算未完成，不是“下次补”。

图签必须能签得下去：工程名称、图名、图号、比例、设计／制图／校对／审核／批准、日期、版次，八项齐全。同一幅面只保留一套图签——图框块自带图签时，不要再外插重复的图名／图号块，否则打印叠影、图名与图号互相矛盾。图号宜按“专业—分区—序号”编制（如 E-07-301～316），目录张数必须与图签张数一致。

第五篇　工具库与模板

前面四篇解决"这一张图画得快、画得对"。第五篇解决更上游的问题：下一个项目来了，怎么不用从头开始。核心是把散在几十个 dwg 里的符号、规则、表格收进一套可调用的工具库——四层结构，缺一层就会退回"每次翻旧图"。

28　样板 DWT：图层、文字样式、图框

样板是"新建图纸时的默认状态"。从三套旧图里挑最规范的一张，清空图面内容，按下面步骤改造：

  1. SAVEAS 另存 _基图.dwg，原图不动。
  2. 框选全部 → E 删除，只留图框（图框要留）。
  3. PURGE 全清（勾嵌套项目），重复三次到无可清理；AUDIT → Y 修复。
  4. 删空图层：旧图动辄上百个图层，留下的都是以后会选错的。
  5. 加载 ZNK-TOOLS.lsp → ZNK-LAY 建 16 个标准图层、ZNK-STY 建文字样式。
  6. SAVEAS → 类型选 图形样板 (*.dwt) → 存 智控深化-A1.dwt；OPTIONS → 文件 → 样板设置里把它设为默认。

文字样式两条纪律：高度填 0（0 = 随标注设置，填了固定值以后就不能临时改字号）；中文样式用 txt.shx + gbcbig.shx 大字体组合，别用花体，缺字体就是问号。

29　块库与工具选项板

新建一个 智控块库.dwg（用样板，存固定位置），只存块不画图。收块别一个个 WBLOCK——设计中心批量搬：

  1. 打开块库 dwg，Ctrl+2 设计中心，左侧树展开旧图 → "块"。
  2. 右侧列出全部块带预览，按住 Ctrl 多选 → 右键"插入"或直接拖到绘图区，块定义就进了块库。
  3. 收前先 ZNK-BLK 看这张图的块清单（按插入次数排序，同目录出 txt）——次数多的是主力符号，次数 1 的多是垃圾。
  4. 重复名先 RENAME 改名再收，块名重复 CAD 会让你二选一，选错后面全乱。

30　图例表、设计说明与点表

这部分慢，是因为每次都在"重写文字"而不是"改参数"。

  • 图例表：行数常变的用 TABLE（表头存成表格样式），基本固定的做成带属性的块整块插入。列固定为：图例 / 名称 / 功率 / 光束角 / 色温 / 控制协议 / 安装方式 / 供电。
  • 设计说明：写成"条款 + 填空"结构（工程概况、设计依据、系统组成、控制策略、施工要求、调试与验收六章），整段存成多行文字块 LG-NOTE-STD，新项目双击改【】里的内容。
  • 点表：给符号块加四个属性——编号、型号、回路、楼层（BEDIT → ATTDEF）。之后 DATAEXTRACTION 一次导出全图设备清单，按楼层按类型汇总——报量靠 CAD，不靠手数。

配套 智控工具库\模板\智控图例表-三方案模板.xlsx：有线（DALI·CBUS）、无线（蓝牙 Mesh）、自组网（GS-Linker）三张图例表 + 六章设计说明模板，填上型号整表复制，PASTESPEC → "AutoCAD 图元"直接进图。

31　新项目 SOP 与回路编号规范

工具库建好后，每张新图按七步走，不要凭感觉：

  1. QNEW 用样板新建；
  2. XATTACH 附着建筑底图（不要打开底图直接画，更不要 INSERT 当块插）；
  3. 选中底图特性里"淡显"设 30，图层锁定；
  4. 坐标不一致用 ALIGN 按轴网对齐；
  5. 选项板点符号布点，灯具按密度规则先大面后局部；
  6. 总线 PLINE 画在 E-BUS 层，编号文字放 E-TXT 层；
  7. 插入图例块改型号 → DATAEXTRACTION 出点表 → 检查回路号无重复。

附录 A　十条补充技巧

不在工序主线上，但真到用时能省事。前七条在第一篇各节里出现过，这里集中列一遍便于记。

  1. OOPS 只反悔删除：删杂线 → BO 建边界 → 填充 → OOPS 找回杂线，中间其它操作不受影响。
  2. 偏移与缩放支持除法：100/3 均分、50/80.25 缩到目标宽度。
  3. TR / EX 空回车：不选边界直接回车，全部对象当边界；TR 内按 F 栏选。
  4. F 圆角半径 0：两根不相接的线一步接齐，常常比 TR 快。
  5. RO / SC / CO 命令内选 C：复制旋转、复制缩放，一步顶三步。
  1. M2P 捕两点中点：找中点不用画辅助线。
  2. PE → J 合并散线：交图前把散线合成多段线，O 才能整体偏移。
  3. Ctrl+9 找回命令行，Ctrl+0 全屏看图：界面乱了先按这两个。
  4. 双击鼠标滚轮 = Z+E：最高频的视图操作，比输入命令快。
  5. @ 相对坐标：@50,0 向右 50，@100<45 长 100 方向 45°，画准尺寸全靠它。

附录 B　恢复默认设置

三种情况对应三种程度的恢复，由轻到重：

  1. 只乱了个别设置：OP → 配置 → 重置，恢复当前配置档的全部设置，图纸文件不受影响。
  2. 界面 / 键位被动过：开始菜单 → AutoCAD 2020 程序组 →「重置设置为默认值」官方工具，或 WS → 工作区重置、CUILOAD 卸载别人的自定义文件。
  3. 彻底恢复出厂（2026-11-17 实操过的流程）：
    1. 关闭 AutoCAD（任务管理器确认 acad.exe 结束）；
    2. 备份：注册表 HKCU\Software\Autodesk\AutoCAD\R23.1 整键导出 + %APPDATA%\Autodesk\AutoCAD 2020\R23.1 目录整份拷贝；
    3. 删除上述注册表键；把 Roaming 下的 R23.1 改名（如 R23.1.old-日期）；
    4. 重新打开 AutoCAD，首次启动自动重建全部默认配置。
